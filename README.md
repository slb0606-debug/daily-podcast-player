## 文件说明

- `podcasts.json` - 播客配置
- `fetch_podcasts.py` - 抓取脚本
- `daily_playlist.html` - 生成的播放列表页面

## 使用方式

```bash
python3 fetch_podcasts.py
```

运行后打开 `daily_playlist.html` 即可浏览今日播客列表。
